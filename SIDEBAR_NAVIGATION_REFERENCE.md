# Sidebar Navigation Reference

## Superadmin Panel Structure

### 🎛️ Panel de control (Control Panel)
- **Usuarios** - User management
- **Roles** - Role management

### 💰 Caja (Cash Register)
- **Apertura de caja** - Cash opening
- **Corte de caja** - Cash closing
- **Corte parcial al cajero** - Partial cashier closing
- **Historico de caja** - Cash history

### 🏭 Almacén (Warehouse)
- **Articulos** - Products/Articles

### 🛒 Compras (Purchases)
- **Entradas de productos** - Product entries
- **Detalle entradas** - Entry details
- **Proveedores** - Suppliers

### 📦 Pedidos (Orders)
- **Lista de pedidos** - Order list

### 💵 Ventas (Sales)
- **Posventa** - Point of sale
- **Detalle Ventas** - Sales details
- **Ventas por ecommerce** - E-commerce sales
- **Clientes** - Customers

### 📄 Cotizaciones (Quotes)
- **Generar cotizacion** - Generate quote
- **Listado cotizacion** - Quote list

### ↩️ Devoluciones (Returns)
- **Devolucion venta** - Sale returns

### 📊 Reportes (Reports)
- **Reportes graficos** - Graphic reports

### ⚙️ Configuracion (Configuration)
- **Datos de la empresa** - Company data
- **Datos del banner** - Banner data

### 🤖 Manage Documentation (Superadmin Only)
- **All Articles** - View and manage all documentation
- **Create New Article** - Add new documentation content
- **View Documentation** - Access public documentation center
- **AI Help Bot** - Test and manage AI chatbot

### 🆘 Help & Support (All Users)
- **AI Help Bot** - Get AI-powered assistance
- **Documentation Center** - Browse and search documentation

## Navigation Features

### Active State Indicators
- Current page is highlighted in the sidebar
- Parent menu items expand when child is active
- Breadcrumb navigation shows current location

### Permission-Based Access
- Menu items are shown based on user permissions
- Superadmin sees additional management options
- Regular users see only Help & Support section

### Responsive Design
- Sidebar collapses on mobile devices
- Hamburger menu for mobile navigation
- Touch-friendly interface

## Quick Access Tips

### For Superadmins
1. **Documentation Management**: Use "Manage Documentation" section
2. **User Management**: Access through "Panel de control"
3. **System Configuration**: Use "Configuracion" section
4. **Reports**: Access through "Reportes" section

### For Regular Users
1. **Help & Support**: Use "Help & Support" section
2. **Documentation**: Access through "Documentation Center"
3. **AI Assistance**: Use "AI Help Bot"

## Troubleshooting

### Menu Not Showing
1. Check user permissions
2. Verify authentication status
3. Clear browser cache
4. Check route permissions

### Active State Issues
1. Verify current route matches
2. Check route naming conventions
3. Clear application cache

### Mobile Navigation
1. Use hamburger menu on mobile
2. Tap to expand/collapse sections
3. Swipe to navigate on touch devices

## Best Practices

### Navigation Organization
1. Group related functions together
2. Use clear, descriptive labels
3. Maintain consistent icon usage
4. Follow logical hierarchy

### User Experience
1. Keep navigation simple and intuitive
2. Provide clear visual feedback
3. Ensure accessibility compliance
4. Test on different devices

### Performance
1. Minimize menu depth
2. Use efficient route caching
3. Optimize permission checks
4. Implement lazy loading where appropriate
